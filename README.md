# Krushi Saathi frontend

React and Vite frontend for the Krushi Saathi farmer chat experience. It includes the landing page, farmer sign-in and sign-up, chat history, chat deletion, and Marathi, Hindi, and English interface options.

## Run locally

```sh
npm install
npm run dev
```

The UI expects the Krushi Saathi API at `http://127.0.0.1:8000/api` by default. To use another API server, set `VITE_API_BASE_URL` in a local `.env` file. See `.env.example`.

## Build

```sh
npm run build
```
